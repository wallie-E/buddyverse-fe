# 搭子社区应用

一个现代化的搭子社区平台，帮助用户找到志同道合的伙伴。使用 React + TypeScript + TailwindCSS 构建，支持 PC 端和移动端适配。

## 🎨 设计特色

- **现代美观**：采用渐变色彩和圆角设计，视觉效果出色
- **响应式设计**：完美适配桌面端和移动端设备
- **用户友好**：直观的交互设计和流畅的动画效果
- **分类丰富**：支持多种搭子类型，如干饭、学习、运动、游戏等

## ✨ 功能特性

### 🏠 首页
- 展示所有帖子列表
- 分类筛选功能（干饭搭子、学习搭子、运动搭子等）
- 细分类型过滤
- 响应式卡片布局

### 🔐 用户系统
- 邮箱 + 密码登录/注册
- 个人资料管理
- 用户统计信息

### 📝 帖子功能
- 发布 150 字以内的帖子
- 支持位置信息
- 丰富的分类系统
- 帖子互动（评论、分享）

### 💬 评论系统
- 一级评论和二级回复
- 实时通知提醒
- 评论管理

### 📱 移动端优化
- 底部导航栏
- 触摸友好的交互
- 移动端专属布局

### 🔔 通知中心
- 评论通知
- 回复通知
- 未读消息管理

## 🚀 技术栈

- **前端框架**: React 19 + TypeScript
- **样式框架**: TailwindCSS 4.0
- **图标库**: Heroicons
- **构建工具**: Vite 7.0
- **开发工具**: ESLint + TypeScript ESLint

## 📦 项目结构

```
src/
├── components/          # 公共组件
│   ├── Header.tsx      # 头部导航
│   ├── PostCard.tsx    # 帖子卡片
│   └── CategoryFilter.tsx # 分类过滤器
├── pages/              # 页面组件
│   ├── HomePage.tsx    # 首页
│   ├── LoginPage.tsx   # 登录页
│   ├── CreatePostPage.tsx # 发布帖子
│   ├── ProfilePage.tsx # 个人资料
│   ├── NotificationsPage.tsx # 通知中心
│   └── MyPostsPage.tsx # 我的帖子
├── types/              # TypeScript 类型定义
├── constants/          # 常量和配置
├── data/              # 模拟数据
└── App.tsx            # 主应用组件
```

## 🛠️ 安装和运行

### 环境要求
- Node.js >= 20.19.0
- npm 或 yarn

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

### 代码检查
```bash
npm run lint
```

## 🎯 主要特色

### 1. 分类系统
- **主分类**: 干饭搭子、学习搭子、运动搭子、游戏搭子、二次元搭子、旅行搭子
- **细分类型**: 每个主分类下包含多个具体的细分选项
- **智能过滤**: 支持多级筛选，快速找到感兴趣的内容

### 2. 响应式设计
- **桌面端**: 宽屏布局，充分利用屏幕空间
- **移动端**: 底部导航，单手操作友好
- **平板端**: 自适应布局，最佳视觉体验

### 3. 用户体验
- **流畅动画**: 页面切换和交互动画
- **直观操作**: 一致的设计语言和交互模式
- **即时反馈**: 加载状态和操作提示
